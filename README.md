# PoGoBot

Old Deprecated Pokemon Go bot because I was bored

Plug an Android phone running into the computer, and open Pokemon go, then run ```python3 main.py```

The bot simply clicks randomly around the middle of the screen while constantly taking a screen capture of the screen and writing over the old one in order to search for pokestops, pokemon, gyms, etc. It finds them by taking captures of the screen, then looking at the individual pixel orientations to determine what screen it is on.
When it has found one, it will automatically catch the pokemon, spin the pokestop, etc.

Calculator for amount of XP gained included.
Pretty rudimentary bot tbh
